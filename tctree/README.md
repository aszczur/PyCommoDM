# TC-Tree (Temporal Cuts Decision Tree)

TC-Tree is a decision tree classifier for temporal data. The algorithm extends classical decision trees by introducing temporal cuts.

## Contents

- TC-Tree classifier implementation (`tctree.py`)
- Example usage script (`demo_tctree.py`)
- Sample datasets (`data/`)

## Usage

See `demo_tctree.py` for a complete workflow including:
- loading temporal data,
- training a TC-Tree model,
- making predictions,
- evaluating classification performance.
