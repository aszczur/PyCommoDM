# PyCommoDM

PyCommoDM is a Python library containing implementations of classification algorithms, temporal data analysis methods, and other data mining techniques developed and used in scientific research.

The repository is organized into separate directories, each containing the implementation, documentation, and usage examples for a specific method or algorithm.

## Repository Structure

Each method is provided in its own directory and may include:

- source code,
- example datasets,
- usage examples,
- method-specific documentation,
- citation information.

## Included Methods

Examples of methods available in this repository include:

- TC-Tree (Temporal Cuts Decision Tree),
- behavioral pattern analysis method for temporal data,
- additional classification and data analysis algorithms.

The list of methods may expand over time as new implementations are added.

## Getting Started

Each method directory contains its own documentation and example scripts demonstrating how to load data, build models, perform predictions, and evaluate results.

Refer to the corresponding method directory for detailed instructions.

## Citation

If you use software, algorithms, or implementations from this repository in academic research, please cite the corresponding publication associated with the method being used.

### TC-Tree (tctree)
